#boutique  ivory

A full-stack e-commerce website built with **Symfony**, featuring product management, shopping cart and checkout, **Stripe payments**, automated transactional emails, and an integrated **AI chatbot** to assist customers with product discovery and recommendations.

---

## Overview

This project is an online store designed to provide a complete shopping experience from product discovery to order completion.

The platform combines a traditional e-commerce backend with automated services and an AI-powered chatbot.

### Main Features

- Product catalog and product details
- Product categories
- Shopping cart
- Order management
- Secure checkout
- Stripe payment integration
- Automated transactional emails
- Customer account management
- AI-powered customer chatbot
- Order and payment status handling
- Responsive web interface
- Admin dashboard : full control of the website

---

## Tech Stack

### Backend

- **Symfony**
- PHP 8.5
- Doctrine ORM
- Symfony Security
- Symfony Mailer
- Symfony Messenger

### Database

- MySQL
- Doctrine ORM

### Payments

- **Stripe**
- Stripe Payment APIs
- Webhooks for payment status synchronization

### chatbot

- llama 3.2
- Product recommendation system
- Database-backed product retrieval

### Frontend

- Twig
- HTML
- CSS
- JavaScript
